# Chelsea-Player-Analytics-App

Project Overview
An interactive web application designed to fetch and display real-time athlete statistics for the Chelsea FC 2023 season. This project demonstrates the ability to integrate third-party REST APIs with a responsive frontend interface.

Core Functionality
Live Data Fetching: Utilizes the Fetch API to retrieve player data from api-sports.io.

Recursive Pagination: Implemented a custom function to handle multi-page API responses, ensuring a complete local dataset.

Interactive UI: Features a real-time search bar and a random player generator that updates the DOM dynamically without page refreshes.

Data Filtering: Automatically filters the roster to show only players with active minutes in the 2023 season.

Note: This project uses a free-tier API key for demonstration purposes.
